⚙️ Ajustes del Panel
PANEL
💡 Cómo usar Ajustes del Panel
  • ID del Panel: identificador único en el YAML, sin espacios.
  • Permiso Default: permiso requerido para abrir el panel. Usa default para todos.
  • Comandos de Apertura: separados por coma, ej. rewards, r.
  • commands-on-open: comandos de consola que se ejecutan cada vez que se abre el panel, uno por línea.
  • panelType: static no refresca, nocommand desactiva comandos de apertura, unclosable bloquea ESC.
  • Fondo: material que rellena los slots vacíos del inventario.
static Panel estático, no se refresca
nocommand Sin comandos de apertura

unclosable El panel no se puede cerrar con ESC

📝 Lore & Botones
LORE
💡 Cómo usar Lore & Botones
  • Lore Superior: texto visible en todos los slots. Soporta & y #HEX para colores.
  • Mostrar progreso: en lugar de %placeholder%/requisito, muestra el valor requerido con el progreso actual del jugador al lado. Ej: &fDinero: &a1000 &7(llevás %vault_eco_balance%). Puedes personalizar el color, el texto antes (llevás ) y después ()) del placeholder.
  • Comandos de estado: cada estado (Bloqueado, Reclamar, Completado) tiene su propio msg= y sound=.
  • Añadir comando: agrega líneas extra al bloque commands: de cada estado, ej. console= eco give ....
  • Estados: Bloqueado muestra requisitos faltantes, Reclamar ejecuta las recompensas, Completado confirma el nivel ya reclamado.

📊 Requisitos
REQS
💡 Cómo usar el Sistema de Requisitos
  • Variable PlaceholderAPI: placeholder evaluado en tiempo real, ej. %vault_eco_balance% para dinero.
  • Base + Aumento/Lv: el valor requerido escala por nivel. Ej: Base 1000 + Aumento 500 → nivel 3 pide 2000.
  • Niveles: separa por coma para restringir el requisito a niveles específicos, ej. 1,3,5. Vacío = todos los niveles.
  • Color: código de color para el valor en el lore, ej. &a verde, &c rojo o #HEX.
  • Añadir Requisito: puedes tener múltiples requisitos por nivel con diferentes variables y rangos de niveles.
🎁 Recompensas
2 ACTIVAS
💡 Cómo usar el Sistema de Recompensas
  • Comando: ejecutado en consola al reclamar. Usa {val} para la cantidad calculada y {lv} para el nivel.
  • Multiplicar x Lv: cantidad × nivel, escala progresivamente. Ej: 100 × nivel 5 = 500.
  • Fijo: entrega siempre la misma cantidad sin importar el nivel.
  • Niveles: separa por coma para aplicar solo en niveles concretos, ej. 2,4,6. Vacío = todos.
  • Toggle: desactiva la recompensa sin eliminarla, no aparece en el YAML.
  • Añadir Recompensa: puedes apilar múltiples comandos por nivel, ej. dinero + items + permisos.
🔑 LuckPerms
LP
💡 Cómo usar LuckPerms
  • Permiso de Nivel: se otorga automáticamente al reclamar, formado como permiso.{lv}, ej. recompensa.reclamada.3.
  • Comando LP: ejecutado en consola para asignar el permiso. Usa {perm} y {lv} como variables.
  • El panel verifica con HASPERM si el jugador tiene el permiso para mostrar el estado Completado.
  • Sin LuckPerms configurado el sistema no podrá marcar niveles como completados.
🗺️ Layout
INV
💡 Cómo usar el Layout
  • Patrón: distribución de los slots de recompensa dentro del inventario.
  • Filas (rows): tamaño vertical del menú, de 1 a 6. Si los slots no caben aparece una advertencia.
  • Nivel Inicial: primer nivel generado, útil para dividir en varios archivos YAML.
  • Cant. Slots: cuántos niveles generar. Cada slot verde en la previsualización = un nivel.
  • Items Extra: slots decorativos o funcionales adicionales con material, nombre, lore y comandos propios.
  • Slots vacíos se rellenan con el Fondo configurado en Ajustes del Panel.
